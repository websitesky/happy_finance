# Happy Finance: сайт

Статичний сайт без збірки: `index.html`, `styles.css`, `script.js`, `config.js`.

## Запуск
У корені `сайти` є `.claude/launch.json` з конфігом `happy-finance` (порт 8801). Або вручну:

```bash
python -m http.server 8801 --directory happy-finance/site
```

Відкрити http://localhost:8801. Параметр `?clean` ховає жовті позначки «заглушка».

## Варіанти блоку послуг
`variants.html` (http://localhost:8801/variants.html): 4 варіанти на вибір (редакційний список, шоурум, рифлені рейки, сходи зростання). Після вибору переносимо в `index.html`.

## Що замінити
- Контакти, Telegram, графік: `config.js`.
- Фото кладуться в `assets/photos/` з такими іменами (без файлу показується слот):
  `maria-hero.jpg` (4:5), `maria-about.jpg` (4:5), `team-1.jpg` ... `team-4.jpg` (3:4).
- Фото з брендбуку вже лежать у `assets/photos/` і підключені:
  `brand-hands.jpg` (перший екран, руки над столом), `brand-desk.jpg` (фон блоку послуг, стіл із зошитом і клавіатурою), `brand-folder.jpg` (фон фінальної форми, папка в руці), `brand-card.jpg` (фон підвалу, візитка зі срібним логотипом). Заміна: той самий файл із тим самим іменем.
- Ціни: у `index.html` шукати `XXX грн`.
- Відгуки, імена команди, сертифікати: блоки з позначкою «заглушка».

## Заявки в Telegram
Токен бота в `config.js` класти не можна, його видно в браузері. Для реального сайту:
у `config.js` вказати `lead.endpoint` (адреса проксі, наприклад Cloudflare Worker, який
приймає JSON `{name, contact, topic}` і пересилає в бот). Без endpoint форма працює в
демо-режимі: перевірка полів, повідомлення про успіх, запис у консоль.

## Дизайн
- Кольори з брендбуку: `#102662`, `#FFFFFF`, `#FB6835` (тільки кнопки і точкові акценти), `#CAAE99`.
- Шрифти: Montserrat (заголовки), Manrope (текст), обидва з кирилицею.
- Іконки: Phosphor. Тема світла, з темним варіантом за налаштуванням системи.
- Логотип «H у рамці» намальований кодом (`assets/mark.svg`); замінити на оригінал з брендбуку.
